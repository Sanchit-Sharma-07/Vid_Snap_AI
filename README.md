# 🎬 VidSnap AI

VidSnap AI is an AI-powered application that automatically generates short-form videos from user-provided text using Text-to-Speech and video processing techniques.

## ✨ Features

- AI-powered video generation
- Text-to-Speech narration
- Automatic subtitle generation
- Background video integration
- Modern web interface
- Download generated videos

## 🛠️ Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- FFmpeg
- ElevenLabs API
